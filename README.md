# Where Is My Car — v1.9.10 final

Aplicación Android para guardar y encontrar la ubicación del coche.

## Funciones

- Guardado manual y navegación hasta el coche.
- Aparcamiento automático mediante el Bluetooth/radio del coche.
- Widget de pantalla de inicio.
- Seis carrocerías cenitales detalladas y originales, sin marcas comerciales.
- Siete colores: naranja, rojo, azul, negro, blanco, verde y amarillo.
- Ajustes completos en una sola pantalla, sin desplazamiento.
- Zona segura automática para que los ajustes no se superpongan con la hora ni los iconos del sistema.
- Interfaz en inglés, español, francés, italiano, bosnio, ruso y chino.

## Compilación

El workflow `.github/workflows/build-apk.yml` genera `WhereIsMyCar-v1.9.10.apk`.
Si se configuran los secretos de firma indicados en el workflow, también genera
`WhereIsMyCar-v1.9.10-PlayStore.aab` firmado para Google Play.
